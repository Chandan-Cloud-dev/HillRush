# 🏍️ Hill Rush - Offroad Adventure

An original 2D off-road motorcycle racing game built using
HTML, CSS, JavaScript, and the HTML5 Canvas API.

Ride through rolling hills, collect coins, manage fuel,
and try to travel as far as possible without crashing.

## ✨ Features

- Procedurally generated rolling terrain
- Physics-based motorcycle movement
- Rotating wheels and animated rider
- Hills, trees, rocks, bushes, and clouds
- Collectible coins
- Fuel pickups and fuel management
- Distance and speed tracking
- Air rotation and landing mechanics
- Particle effects
- Sound effects with mute control
- Pause and restart functionality
- Keyboard controls for desktop
- Touchscreen controls for mobile
- Responsive gaming interface
- Original canvas-drawn graphics

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API
- Web Audio API

No external game engine is required.
